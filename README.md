# Aqua Nook Product Landing Page

A responsive product landing page for a fictional beginner aquascaping-kit brand called Aqua Nook.

The project presents a calm, immersive product experience for people who want to build their first planted aquarium at home. It includes product options, a newsletter form, feature sections, and a video area.

## Features

- Sticky navigation bar with anchor links
- Immersive hero section with a layered image overlay
- Email sign-up form with accessible labels
- Feature-card layout
- Three-step setup process
- Responsive video area
- Three product-kit options
- Highlighted recommended kit
- Responsive mobile design

## Built With

- HTML5
- CSS3

## What I Practiced

- Flexbox and CSS Grid layouts
- `linear-gradient()` overlays
- `background-size: cover` and image positioning
- Responsive typography with `clamp()`
- Using `aspect-ratio` for video content
- Card layouts with consistent button alignment
- Interactive hover and focus states
- Semantic forms, navigation, sections, and lists

## Project Reference

This project is an original redesign inspired by the freeCodeCamp Responsive Web Design Product Landing Page assignment.
